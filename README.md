# Dotfiles

My personal dotfiles, managed with `stow`.

## Installation

To install these dotfiles, clone the repository and then use `stow` to create the necessary symlinks:

```bash
git clone https://github.com/your-username/dotfiles.git
cd dotfiles
stow .
```

## Included Configurations

*   **Neovim**: My Neovim configuration.
*   **Tmux**: My Tmux configuration.
*   **Yazi**: My Yazi file manager configuration.
*   **Zsh**: My Zsh configuration.

## Notes

The `.stow-local-ignore` file contains a list of files that should not be stowed.
